# 飞书多维表格创建清单

> 对应实施任务：B01、D01  
> 状态：九表与字段映射已建立；D01 研究候选审核视图已配置并通过用户验收  
> 机器可读基线：`lib/feishu/schema-definition.ts`

## 1. 创建原则

1. 在公司飞书租户内创建一个多维表格应用。
2. 仅创建本文列出的九张表，不使用个人空间作为生产位置。
3. 表名、字段显示名可以服务人工阅读；程序始终使用表 ID 和字段 ID。
4. 真实 ID 只能写入受保护的服务端配置或 GitHub Secrets，不提交到仓库。
5. 内部战投备注表不得授权给 WorkBuddy、OpenAI 或公开网站构建。
6. 网站只能读取经过公开投影的字段，不能直接导出整张表。

## 2. 九张表

| 表 | 主字段 | 用途 | 关键关联 |
|---|---|---|---|
| 研究候选 | 候选 ID | 保存融资、技术、产品和商业化待审核线索 | 可关联重复候选 |
| 融资事件 | 事件 ID | 保存正式融资事实与发布控制 | 单向关联公司 |
| 公司动态 | 动态 ID | 保存技术、产品和商业化进展 | 关联公司和多个来源 |
| 信息来源 | 来源 ID | 保存每条内容的原始链接和可信等级 | 被融资或公司动态引用 |
| 公司 | 公司 ID | 保存公司公开档案 | 反向关联融资与公司动态 |
| 日报 | 日报日期 | 保存三个固定板块与发布状态 | 关联融资和公司动态 |
| 观察清单 | 观察项 ID | 保存重点公司、重点赛道、公众号和关键词 | 无 |
| 内部战投备注 | 内部备注 ID | 保存内部判断与跟进 | 公司或融资事件二选一 |
| 自动化任务 | 任务 ID | 保存幂等、锁、重试和错误 | 无 |

完整字段、类型、选项、是否必填、公开性和说明以
`lib/feishu/schema-definition.ts` 为唯一工程契约。

## 3. 必建审核视图

### 研究候选

| 视图 | 筛选条件 | 必须显示 | 排序 |
|---|---|---|---|
| 今日待审核 | 发现时间为今天；审核状态为 `PENDING` | 候选 ID、标题、来源 URL、来源等级、置信度等级、冲突提示、审核状态 | 置信度分数降序 |
| 高置信度 | 置信度等级为 `HIGH`；审核状态为 `PENDING` | 候选 ID、标题、来源 URL、来源等级、置信度分数、冲突提示、审核状态 | 默认 |
| 低置信度 | 置信度等级为 `LOW` | 候选 ID、标题、来源 URL、来源等级、置信度分数、冲突提示、审核状态 | 默认 |
| 待复核 | 审核状态为 `NEEDS_RESEARCH` | 候选 ID、标题、来源 URL、来源等级、置信度等级、冲突提示、审核状态 | 默认 |
| 重复候选 | 审核状态为 `DUPLICATE` | 候选 ID、标题、来源 URL、来源等级、重复候选、冲突提示、审核状态 | 默认 |

以上视图均为内部审核视图。不得显示规范 URL、完整初步抽取 JSON、版本、创建时间、更新时间或修改人等系统载荷列。

当前飞书表把“相关性”设为主字段。飞书不允许在任何视图中隐藏主字段，因此实际审核视图会在上述业务列之外额外显示“相关性”；这不改变候选业务主键仍为“候选 ID”的项目契约。

## 4. 字段 ID 映射步骤

1. B02 由公司管理员创建飞书自建应用和九张表。
2. 在飞书 OpenAPI 或管理界面取得每张表的 table ID。
3. 取得每个字段的 field ID，不使用字段显示名作为生产定位。
4. 按 `lib/feishu/field-id-manifest.ts` 生成的配置键逐项填写。
5. B04 启动时核对表、字段、类型、关联目标和选项；不一致时快速失败。

映射键示例：

- `FEISHU_TABLE_FUNDING_EVENTS_ID`
- `FEISHU_FIELD_FUNDING_EVENTS_EVENT_ID_ID`
- `FEISHU_FIELD_FUNDING_EVENTS_COMPANY_ID`
- `FEISHU_FIELD_INTERNAL_ASSESSMENTS_INTERNAL_NOTES_ID`

示例只表示配置键格式，不包含任何真实飞书 ID。

## 5. 人工验收

创建完成后，在隔离测试表中添加五条脱敏记录：

1. 一条公司记录。
2. 一条关联该公司的融资事件。
3. 一条关联该公司的技术或产品动态。
4. 一条被融资事件和公司动态关联的原始来源。
5. 一条包含融资与公司动态的日报。

确认：

- 公司能够显示关联融资历史。
- 公司能够显示关联技术、产品和商业化动态。
- 融资事件能够打开关联公司。
- 融资事件和公司动态都至少关联一个可打开的原始链接。
- 日报能够显示“今日融资、技术与产品、商业化进展”三个板块。
- 每个板块按重要性评分降序，且来源链接显示在对应条目内。
- 已发布且允许公开的事件进入“公开已发布”视图。
- 已发布日报进入“已发布归档”视图。
- 内部战投备注字段不出现在任何公开导出或公开视图中。
