# Agent 精简协作约定

> 状态：生效
> 更新日期：2026-08-04
> 适用范围：主 Agent、六个专职子 Agent、临时辅助 Agent 与人工协作

本文档补充 `agent-coordination.md` 的日常执行方式，目标是保留多 Agent 的独立视角，同时减少重复阅读、重复汇报、文件冲突和无效 Token 消耗。如与更高优先级文档冲突，按 `AGENTS.md` 的文档优先级处理。

## 1. 默认协作模式

1. 主 Agent 是唯一任务调度、状态集成和最终交付负责人。
2. 六个子 Agent 是能力池，不是每个任务必须同时启动的固定编制。
3. 每个小任务默认只启用一个执行 Agent；存在真实风险或独立验收价值时，再增加一个 QA Agent。
4. 不让多个 Agent 重复研究同一问题；QA 只复核高风险结论、失败路径和门禁。
5. 子 Agent 不直接彼此反复讨论。各自将增量结果交回主 Agent，由主 Agent 统一集成。

## 2. 适合 Agent 执行的事项

- Schema、格式、业务日、计数和重复检查。
- 批量 URL 状态检查、重定向记录和异常分类。
- 来源汇总、冲突列表和人工核验清单。
- 离线测试、代码检查、敏感字段扫描和可重复验证。
- 按用户已确认的结论执行确定性、边界明确的修改。

Agent 可自主执行只读、离线、可逆且规则明确的检查，但不能据此批准候选、改写原始事实或触发发布。

## 3. 优先交给用户的事项

- 来源内容是否真正支持候选事实。
- 页面日期模糊、隐藏或存在多个口径。
- 融资轮次、金额、事件日期、参与方或交易状态互相冲突。
- 需要登录、验证码、付费权限、微信客户端或个人平台会话。
- 媒体、公众号或搜索渠道的可信度判断。
- 飞书中的候选审核、事实修正、批准、排序和公开决策。
- 会改变产品范围、架构不变量、正式数据源、Provider 职责或公开边界的选择。

## 4. 先询问用户的触发条件

出现以下任一情况时，Agent 应停止无边界深挖，整理证据后由主 Agent 向用户询问：

1. 同一问题经过两轮合理尝试仍无法确认。
2. 继续处理需要登录、验证码、付费账号、个人客户端或新的外部权限。
3. 存在两个都合理但会改变最终结果的处理方案。
4. 来源互相冲突，现有规则无法判定。
5. 需要执行真实 OpenAI 付费调用、飞书写入、通知、push、PR 或发布。
6. 需要修改架构、产品范围、Schema、飞书正式字段、公开 DTO 或 Provider 职责。
7. 继续搜索的预期收益很低，或成本明显高于人工核验。
8. 候选与来源明显不匹配，且没有可靠替代来源。

对用户的询问必须简短包含：

- 已确认事实。
- 未确认点。
- 已尝试的方法。
- 2–3 个可选处理方案。
- 推荐方案及影响。

## 5. 文件权限

| 文件或范围 | 默认权限 |
|---|---|
| `architecture.md`、`PRD.md`、`SPEC.md`、`TECH-STACK.md` | 仅主 Agent 修改 |
| `implementation-plan.md`、`AGENTS.md`、`agent-coordination.md` | 仅主 Agent 修改 |
| `progress.md`、`main-agent-handoff.md` | 仅主 Agent 在集成结论后更新 |
| `search-strategy.md` 和媒体网站清单 | Research Operations 可提交建议或明确授权的补丁；主 Agent 集成 |
| 单次搜索报告、修订报告和 QA 验收报告 | 对应任务 Agent 可修改 |
| 候选 JSON | 仅明确获批的 Research Operations 任务可修改 |
| 业务代码和对应测试 | Implementation Engineer 在任务范围内修改；QA 默认只读 |
| Git、分支、commit、push 和 PR | Release Manager 负责；对外动作仍需用户授权 |

任何 Agent 都不得自行扩大文件范围。发现必须修改共享文件时，先向主 Agent 提交原因和最小补丁建议。

## 6. 任务与交接的 Token 控制

1. 子 Agent 只读取任务必需文档，不默认重读所有长文档。
2. 主 Agent 在任务单中提供必需背景、当前状态和冻结契约。
3. 子 Agent 不重复总结整个项目，不自行更新 `progress.md` 或 `main-agent-handoff.md`。
4. 每次交接只包含：结论、异常项、修改文件、验证命令与结果、已知限制、下一步建议。
5. 主 Agent 只在形成最终集成结论后更新共享状态文档。

## 7. 外部动作与人工门禁

未经用户明确授权，任何 Agent 不得执行：

- 真实飞书数据写入、审核、批准或发布。
- 真实 OpenAI 付费研究调用。
- 真实通知发送。
- commit、push、PR、线上发布或其他对外可见操作。

候选导入不等于候选批准，候选批准不等于正式数据公开，日报生成不等于网站发布。
