# 给 WorkBuddy 的 D05.1 国内昨日试跑指令

> 历史快照：本任务已结束。2026-08-04 起 WorkBuddy 暂停，本文不得作为现行搜索入口。

## 任务

当时依据现已归档的 `docs/archive/search/workbuddy-domestic-observation-list.md`，搜索北京时间 2026-08-02 00:00–23:59 发布的中国 Physical AI、具身智能及上下游动态，并输出一个符合 `docs/workbuddy-candidate-format.md` 的候选 JSON 文件。

## 搜索范围

- 重点公司、机构和组织。
- 重点公众号：公司官号、投资机构、FA、产业媒体、政府与国家或地方基金。
- 重点赛道：具身模型、本体、全栈、世界模型、视频生成、物理仿真、数据采集、机械臂、传感器、灵巧手、物理 AI，以及电机、减速器、丝杠、液冷散热、控制器、芯片、电池等上下游。
- 发现型搜索：允许发现观察清单外的新公司、新玩家、新融资、新技术、新产品和新商业化部署。

## 日期和来源门禁

1. 只收录原始来源明确标注在北京时间 2026-08-02 发布的内容。
2. 日期不明确的内容不要冒充昨日候选；可在交接说明中单列“日期待核验”，但不要写入候选 JSON。
3. 优先公司官方公众号、公司官网、投资机构、FA、监管或政府原文。
4. 产业媒体和转载可以作为线索，但应尽量回溯到原始来源。
5. 每条候选必须有可打开的原始 URL，不得只提供搜索结果页或搜索摘要。
6. 不绕过登录、验证码、付费墙或平台访问控制。

## 内容类型

每条候选必须选择一个：

- FUNDING
- TECHNOLOGY
- PRODUCT
- COMMERCIALIZATION

不要为了填满板块而使用其他日期内容。某一类型没有合格候选时允许为空。

## 输出边界

- 只输出 C01 schemaVersion: "1" 候选 JSON。
- 不生成候选 ID、canonical URL、审核状态、正式事件、公司动态、日报、发布状态或内部战投判断。
- 不保存完整公众号正文，只保留不超过契约长度的必要摘要。
- 相同 URL 命中多个查询词时合并 queries，不要复制候选。

完成后把候选 JSON 保存为独立文件并交给 Codex；Codex 将在用户确认 D05.1 自动化测试通过后，使用 workbuddy-import 写入飞书“研究候选”表。
